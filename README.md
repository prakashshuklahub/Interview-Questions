## What's in here

Every file is one problem: the statement first, then a worked solution with inline comments
explaining *why* the approach works — not just what it does. Where a brute-force answer exists,
the optimal one is called out alongside it.

Topics covered: arrays & hashing, two pointers, sliding window, binary search, stacks,
intervals, matrices, backtracking, greedy, graphs & islands, trees, and a large dynamic-programming set.

## How to use it

1. Pick a problem from the index below.
2. Read the statement, then close the file and try it yourself.
3. Come back and compare — or watch the [video walkthrough](https://www.youtube.com/@TheHustlingEngineer) for the reasoning end to end.
